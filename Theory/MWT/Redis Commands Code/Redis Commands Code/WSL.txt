Alternative: Redis with Docker (also great)
=============================================

Step 1: Install Desktop Docker

Step 2: docker run -d --name redis-stack -p 6379:6379 -p 8001:8001 redis/redis-stack:latest

List containers
docker ps    
docker ps -a 

Start a container
docker start redis-stack

Stop a container
docker stop redis-stack

Restart a container
docker restart redis-stack

Remove container (optional)
docker rm redis-stack

Redis-Stack is exposed onto

http://localhost:8001

Stop / remove
================
docker stop redis-stack
docker rm redis-stack
